# BiletFlow

BiletFlow is an event registration and ticketing project developed for
CSCI 361 — Software Engineering, Fall 2026, at Nazarbayev University.
It includes a web application for discovering events and obtaining free
tickets, a backend API, and a mobile app for staff to scan ticket QR codes
and manage admission.

## Team

Palantir — a five-person student team.

## Current status

Implementation, integration and testing.

The working code and setup instructions are available in the
[integration branch](https://github.com/IliyasNU/palantir/tree/integration/biletflow-e2e).

The initial demo includes event discovery, registration and sign-in,
free ticket issuance, QR display and staff check-in with duplicate protection.
Further mobile features, device acceptance and deployment work are in progress.
